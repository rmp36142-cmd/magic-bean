# Magic Bean

个人版「文案 → AI 视频」工具。素材来自公开免费的 Pexels / Pixabay（也可以上传自有素材），
分镜拆分接入你自己配置的 LLM（任意 OpenAI 兼容接口），配音使用免费的 Edge TTS，
最终用 FFmpeg 真实合成导出 mp4（支持横屏/竖屏/方形、转场、背景音乐、逐句字幕）。
参考产品见 `reference/` 目录里的花生AI截图。

> 接手开发 / 新开会话，请先读 [HANDOFF.md](./HANDOFF.md)：里面有本地启动步骤、架构导览、
> 改代码前必须知道的不变量、哪些功能还没在真实网络下验证过，以及已经踩过的坑。

## 使用流程

1. 首页粘贴口播文案，选好画面比例（16:9 / 9:16 / 1:1），创建项目
2. 点「拆分镜头」——调用你配置的 LLM，把文案拆成若干分镜，每个分镜带画面描述和中/英文关键词
3. 每个分镜点「选择素材」，面板有三个 tab：
   - **推荐**：Pexels/Pixabay 关键词搜索结果，可以改关键词重搜，点右上角星标收藏
   - **收藏**：收藏过的素材库，跨项目复用
   - **我的**：上传自有视频/图片（免费素材库找不到合适画面时用）
4. 点「生成缺失配音」或「全部重新配音」——后台任务，网页显示进度，可随时取消
5. 网页预览播放器可以直接看效果（素材 + 字幕 + 配音）
6. 可选：换音色、上传背景音乐、开关转场效果
7. 点「导出视频」，后端 FFmpeg 合成并产出可下载 mp4；历史版本列表可以下载之前的导出结果
8. 项目 / 分镜 / 上传素材都可以删除；设置页可以看磁盘占用并清理缓存

分镜文案可以直接编辑，编辑后该分镜的配音和字幕会自动失效，需要重新生成。

## 本地运行

```bash
npm install
cp .env.example .env.local   # 填入你自己的 API Key
npx prisma migrate dev
npm run dev
```

打开 http://localhost:3000。设置页 `/settings` 可以在运行时修改 LLM 与素材源的 Key，
并有「测试连接」按钮直接验证配置是否可用，以及磁盘占用统计和缓存清理。

## 部署说明

- 需要能跑原生二进制的服务器/容器（VPS、自建 Docker 等）来运行 FFmpeg 做真实视频合成，
  不能部署在纯 Serverless 平台（如 Vercel）上。
- 部署环境需要安装 `ffmpeg`（`apt install ffmpeg` 或系统对应的包管理器）。
- 需要一个支持中文的字体，否则导出视频里烧录的中文字幕会显示成方块。推荐
  `fonts-noto-cjk`（Debian/Ubuntu：`apt install fonts-noto-cjk`）。字体名可以用
  `SUBTITLE_FONT` 环境变量覆盖，默认 `Noto Sans CJK SC`；找不到时 fontconfig 会自动回退到
  其他中文字体。
- 导出和批量配音都是常驻进程里的后台任务（提交后立即返回，网页轮询进度），需要一个持续运行的
  Node 进程（`npm run start`），不能用请求结束就销毁实例的无服务器函数运行。
- 配音调用的是微软 Edge 朗读服务（`speech.platform.bing.com`），部署环境需要能访问这个域名。

## 一些实现上的说明

- **分镜时长由配音决定**：每个分镜的时间轴长度 = 它自己的配音时长，素材会被裁剪或循环来匹配，
  而不是反过来。所以字幕、画面、配音天然对齐。
- **转场不会破坏时间轴**：开启交叉淡化时，每个分镜的素材片段会在挨着转场的那一侧多渲染半个
  转场时长，正好被 xfade 吃掉，因此成片总时长仍然精确等于各分镜配音时长之和。
- **字幕是逐句的**：每个分镜的文案会按句读切成多条字幕，按字数比例分配时间；换行遵守中文避头尾
  规则（标点不会出现在行首）。字幕以 ASS 格式生成并把 `PlayRes` 钉死为输出分辨率，这样字号和
  边距就是真实像素——否则 libass 会按它自己的 384x288 脚本坐标系缩放，不同比例下字幕大小和位置
  会完全跑偏。
- **后台任务有心跳**：任务运行时会刷新 `heartbeatAt`（ffmpeg 的输出也会刷新它）。心跳变冷的任务
  会被判定为「进程重启后遗留」并自动标记失败，所以一次崩溃不会永久占住这个项目的任务槽位。
- **磁盘**：成片会保留，但全长中间产物（无声视频、拼接后的配音）在导出成功后会立刻删除。素材缓存
  是内容寻址、跨项目共享的，所以不随项目删除而清理——设置页的「清理缓存」会清掉一周未使用的素材
  缓存、失败/孤立的导出目录和无主文件。

## 已知取舍

- 背景音乐是用户自备文件，不是从 API 搜索来的——Pexels/Pixabay 的公开 API 都不含音乐检索
  （Pixabay 网站上有音乐板块，但没有对应的公开 API）。
- 转场效果只有交叉淡化一种，过渡时长按相邻分镜时长自适应（不超过较短分镜时长的一半）。
- 字幕是整句切分，不是逐字高亮。
- 没有多用户/权限体系，是给单人自用设计的，请不要直接暴露在公网上。
