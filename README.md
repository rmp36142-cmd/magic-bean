# Magic Bean

个人版「文案 → AI 视频」工具。素材来自公开免费的 Pexels / Pixabay，分镜拆分接入你自己配置的
LLM（任意 OpenAI 兼容接口），配音使用免费的 Edge TTS，最终用 FFmpeg 真实合成导出 mp4（支持转场
和背景音乐）。参考产品见 `reference/` 目录里的花生AI截图。

- [x] Phase 4 — TTS 配音 + 字幕时间轴 + 网页预览播放器

## 使用流程

1. 首页粘贴口播文案，创建项目
2. 点「拆分镜头」——调用你配置的 LLM，把文案拆成若干分镜，每个分镜带画面描述和中/英文关键词
3. 每个分镜点「选择素材」——从 Pexels/Pixabay 搜索结果里选一个视频/图片；分镜文案可以直接编辑，
   编辑后原有配音会自动失效，需要重新生成
4. 点「生成全部配音」（或对单个分镜「重新生成配音」）——为每个分镜生成配音（Edge TTS，免费，
   无需 Key），分镜的时间轴长度由配音时长决定
5. 网页预览播放器可以直接看效果（素材+字幕+配音）
6. 可选：上传背景音乐（自备音频文件，导出时会以低音量混入配音下方）；勾选/取消「转场效果」决定
   分镜之间是硬切还是交叉淡化
7. 都配置好之后点「导出视频」，后端 FFmpeg 会把所有分镜素材裁剪/循环匹配配音时长、（可选）交叉
   淡化拼接、烧录字幕、混入配音和背景音乐，产出可下载的 mp4，网页轮询显示进度；同一项目同时只能
   有一个导出任务在跑，历史版本列表可以看到并下载之前的导出结果
8. 项目/分镜都可以删除

## 本地运行

```bash
npm install
cp .env.example .env.local   # 填入你自己的 API Key
npx prisma migrate dev
npm run dev
```

打开 http://localhost:3000。设置页 `/settings` 可以在运行时修改 LLM 与素材源的 Key，并有「测试
连接」按钮直接验证配置是否可用。

## 部署说明

- 需要能跑原生二进制的服务器/容器（VPS、自建 Docker 等）来运行 FFmpeg 做真实视频合成，
  不能部署在纯 Serverless 平台（如 Vercel）上。
- 部署环境需要安装 `ffmpeg`（`apt install ffmpeg` 或系统对应的包管理器）。
- 需要至少一个支持中文的字体（比如 `fonts-wqy-zenhei` 或 `fonts-noto-cjk`），否则导出视频里
  烧录的中文字幕会显示成方块。
- 导出是常驻进程里的后台任务（提交后立即返回，网页轮询进度），需要一个持续运行的 Node 进程
  （`npm run start`），不能用请求结束就销毁实例的无服务器函数运行。
- 配音调用的是微软 Edge 朗读服务（`speech.platform.bing.com`），部署环境需要能访问这个域名；
  默认语音是 `zh-CN-XiaoxiaoNeural`，想换声音改 `src/lib/tts/edgeTts.ts` 里的 `DEFAULT_VOICE` 常量。

## 已知取舍 / 后续可扩展

- 字幕粒度是"每个分镜一段"，不是逐字/逐词高亮；如果分镜文案较长，字幕会一次性显示整段。
- 素材缓存（`public/storage/materials/`）是跨项目共享、内容寻址的，不会随项目删除而清理，长期
  使用需要自行清理磁盘；每个分镜自己的配音、每次导出的产物在删除分镜/项目时会自动清理。
- 背景音乐是用户自备文件，不是从 API 搜索来的——Pexels/Pixabay 的公开 API 都不含音乐/音效检索
  （Pixabay 网站上有音乐板块，但没有对应的公开 API），所以这块没法做成"素材搜索"的形式。
- 转场效果目前只有一种（交叉淡化 fade），过渡时长按相邻分镜时长自适应（不会超过较短分镜时长的
  一半），没有做转场类型选择。
- 没有做逐词高亮字幕、AI 自动配乐推荐等更高级的增强。
